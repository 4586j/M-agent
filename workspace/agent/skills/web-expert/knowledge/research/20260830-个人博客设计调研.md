## 发现与可复用要点

### 1. 2026 动效趋势与性能纪律

- 滚动驱动动画（scroll-driven）是第一趋势：原生 CSS Animation Timeline 约 85% 浏览器支持；社区一致建议用 **IntersectionObserver + requestAnimationFrame** 驱动，效果仅用 transform/opacity 保证 60fps。
- 动效定位从"装饰"转向"功能"：动效要引导视线、表达状态，而不是堆砌。
- 光标特效已从"小圆点跟随"进化到流体/拖尾模拟（Lusion 类 WebGL 效果）；单文件零依赖场景可做"发光点 + 延迟跟随环"的轻量版。
- Canvas 粒子是经典底座（particles.js 一脉）：星空/微光粒子 + 鼠标视差，数量与尺寸控制好即可既炫酷又省性能。

- 来源：[State of Web Animation 2026](https://annnimate.com/state-of-web-animation)、[Web design trends 2026](https://done.lu/web-design-trends-2026-what-you-need-to-know/)、[Josh Comeau：Scroll-Driven Animations](https://www.joshwcomeau.com/animation/scroll-driven-animations/)、[scroll-driven-animations.style](https://scroll-driven-animations.style/)、[Codrops cursor demos](https://tympanus.net/codrops/hub/tag/cursor/)、[Awwwards GSAP 精选](https://www.awwwards.com/websites/gsap/)

### 2. 深色个人博客的设计共性

- 背景：近黑（#0a0a0a~#111 一带）而非纯黑；文字用柔和的米白/浅灰，避免纯白刺眼。
- 分层：低对比度表面色区分层级（elevated surface），而不是用阴影硬分。
- 排版驱动：大标题 + 宽松行高 + 等宽字体点缀代码/数据，正文行高 ≥1.7。
- 开发者博客标配元素：极简导航、阅读时长标注、标签系统、社交链接、明暗切换（本项目按用户"炫酷"定位选纯深色）。
- 值得研究的对象：Lee Robinson（极简排版）、Linear Blog（产品级深色）、Dark.Design 画廊。

- 来源：[Dark.Design](https://www.dark.design/)、[Dark Mode Websites: 10 Stunning Examples That Actually Work](https://lovable.dev/guides/dark-mode-website-examples-guide)、[Blogging for Devs：最佳开发者博客](https://bloggingfordevs.com/react-blogs/)、[Creative Tim：深色主题](https://www.creative-tim.com/blog/web-design/top-dark-website-themes/)

### 3. 技术选型信号

- 2026 流行组合是 React + GSAP + Lenis，但零依赖 vanilla（IntersectionObserver/rAF/CSS 动画）完全可实现同类效果且无构建步骤——对单文件演示页更合适（待 ADR-003 确认）。

## 追加调研：鼠标放大镜特效（2026-08-30，用户新增需求）

- 检索：magnifier lens cursor effect DOM zoom lens clone / canvas magnifier vanilla
- 结论：放大"活 HTML 内容"的标准零依赖方案是**克隆法**——`cloneNode` 复制内容 → 圆形裁剪容器（overflow:hidden + border-radius:50%）→ 克隆体 `transform: scale(Z)` + 反向平移对齐光标点；图片/画布类内容用 canvas `drawImage(src, sx, sy, w/Z, h/Z, 0,0, w, h)` 实时放大。
- 来源：[Scale any type of content under 'magnifying' div（SO）](https://stackoverflow.com/questions/24732305/scale-any-type-of-content-under-magnifying-div)、[Creating Magnifying Glass Effects（Medium）](https://medium.com/@ignatovich.dm/creating-magnifying-glass-effects-in-html-css-and-javascript-7d42083bdf0e)、[Magnifying Glass for Text（DEV）](https://dev.to/eitanwaxman/magnifying-glass-for-text-and-more-5a57)、[4 JavaScript Magnifying Glasses](https://freefrontend.com/javascript-magnifying-glasses/)
- 本项目应用：双层透镜——底层 lens-canvas 实时放大星空画布，上层 lens-world 克隆 nav+main+footer（canvas 在克隆体中为空 → 星空从透明区域透出，与真实层级一致）；克隆时补 `.visible`/进度条宽度，避免透镜看到"未显现"的空白区块。

## 追加调研：2048 与网页桌宠（2026-08-30，用户新增需求 F16/F18）

- 检索：2048 vanilla js 实现 / web page desktop pet walking character
- 2048 结论：核心 = 4×4 二维数组 + 每方向"压缩→相邻合并→再压缩"+ 空位随机生成 2(90%)/4(10%) + 无空位且无可合并判负；键盘与滑屏双输入。参考：[Medium 逐步教程](https://atikbinmustafij.medium.com/building-the-classic-2048-game-with-html-css-and-javascript-a-step-by-step-guide-9df38ae498dd)、[SO：merge 实现](https://stackoverflow.com/questions/66201957/how-can-i-implement-the-merge-functionality-for-2048)
- 桌宠结论：网页桌宠主流 = CSS 动画角色容器 + JS 沿视口随机游走（Walkabout 模式）；无需 sprite 表，emoji + CSS 关键帧即可保持零依赖。参考：[OpenPets（Walkabout 模式）](https://openpets.dev/)、[Josh Comeau：Sprites on the Web](https://www.joshwcomeau.com/animation/sprites/)、[r/neocities：个人网站宠物挂件讨论](https://www.reddit.com/r/neocities/comments/11ucsxw/html_pets/)
- 本项目应用：桌宠 = 页脚游走小猫（emoji + bob 动画 + 随机折返）+ 点击互动（爱心粒子 + 随机台词气泡）+ 久置入睡 + 🐾 按钮开关（localStorage 持久化）；reduced-motion 下静坐不游走。
