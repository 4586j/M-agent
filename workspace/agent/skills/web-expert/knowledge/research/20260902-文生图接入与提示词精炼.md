## 接口要点（DashScope 兼容，实测）

- **端点**：`POST https://dashscope.aliyuncs.com/api/v1/services/aigc/multimodal-generation/generation`
- **鉴权**：`Authorization: Bearer <key>`；实测平台（qianwenai.com）签发的 sk- 密钥**直连 dashscope 域名可用**
- **模型**：`qwen-image-3.0(-pro)`（size 2048*2048）、`qwen-image`、`qwen-image-plus` 为同步；`wan2.7-image(-pro)` / `wan2.6-t2i` 走异步 tasks（size 用 "1K/2K/4K" 简写）
- **请求体**：
  ```json
  { "model": "qwen-image",
    "input": { "messages": [{ "role": "user", "content": [{ "text": "<提示词>" }] }] },
    "parameters": { "result_format": "message", "watermark": false, "prompt_extend": false, "negative_prompt": "<负面词>" } }
  ```
- **响应**：`output.choices[0].message.content[0].image` = OSS 签名 URL（**约 8 天过期，生成后必须立刻下载**）；`usage` 含实际 width/height（qwen-image 默认出 1664×928，非方形）
- **实测耗时**：单次 5.6s

## 透明背景方案（桌宠浮在深色星空上）

模型**无透明背景参数**（文档通篇无 alpha/透明配置）→ 采用 **纯黑背景 + CSS `mix-blend-mode:screen`**：
黑=完全显示底色、亮部叠加（等效"透明 + 自发光"），天然适配深色页面；代价是图中深色部分也会沉入背景——提示词需让主体用亮暖色并带光晕。
配套约束：提示词强制"纯黑背景/无阴影/无地面/无文字"，且 `prompt_extend:false`（关闭官方提示扩写，防止模型自作主张加场景元素）。

## 提示词精炼（搜集 → 提炼的工程结构）

**结构**：主体与品种色彩 → 姿态与表情细节 → 风格参照（吉卜力/贴纸）→ 光效 → 背景强约束 → 构图占比。

**负面词**（官方模板为基础按需增补）：
`Low resolution, low quality, blurry, open eyes, text, watermark, frame, border, background elements, ground, shadow, multiple cats, humans, hands, deformed anatomy, oversaturated colors, AI-looking artifacts`

**最终正向提示词**（本项目实际使用，产出 `assets/pet-sleep.png`）：

> 可爱的卡通小猫睡觉贴纸：一只橘黄色的小猫侧躺着熟睡，身体蜷成饱满圆润的一团，双眼闭合为两道柔和的弧线，耳朵放松贴伏，尾巴轻轻环住身体，嘴角带着一丝满足的微笑。吉卜力动画风格的柔和手绘质感，线条圆润无尖角，暖橘黄色毛发带有细腻的笔触层次，脸颊有淡淡的腮红。小猫整体散发一圈柔和的暖金色光晕。纯黑色背景，背景完全纯净：无任何物体、无阴影、无地面、无文字。小猫居中构图，占画面约 70%。

## 常见坑（走查实证）

1. 图片 URL 带签名过期 → **生成后立刻下载**，不要热链 OSS 地址
2. 原图 1.2MB（1664×928）→ PIL LANCZOS 缩到 512 宽 + optimize → 127KB（贴纸显示 ~90px，512 已是 5 倍冗余）
3. `prompt_extend` 默认 true，需要精确控制背景/构图时必须显式关掉
4. API 密钥只在 curl 环境变量中使用，**不写入任何仓库文件**；密钥若曾在聊天中出现，建议定期在平台轮换
5. **"黑框"问题**（多张表情图实测）：生成的"纯黑背景"实际是 19-30 的近黑灰 + 光晕渐变，screen 混合下会浮出一层暗框 → 修法：**黑电平压溃**——PIL 实测图片四周边缘亮度上限 t，LUT 把 ≤t 的像素精确压到 0（上方轻微伽马重排），边缘即可保证纯黑；处理后体积还会再降 ~60%。若主体带大面积暗部则改用软羽化 alpha，本例贴纸主体亮色不受影响
6. **角色一致性**：同一段角色描述（品种/毛色/五官/风格/光效/背景句）逐字复用到每张提示词，只改表情/动作子句，六张表情风格统一度可接受；角色描述不要让模型"自由发挥"
7. **mix-blend-mode 会被层叠上下文隔离（关键坑）**：`.pet{position:fixed;z-index:130;will-change}` 自身就是独立合成层，内部元素的 `mix-blend-mode:screen` 只与层内透明背景混合，**够不到页面背景**，黑底照样显示成黑块（canvas 采像素只能证明文件是纯黑，证明不了混合生效）。治本：**亮度→alpha 转真透明**——`alpha=max(R,G,B)`、RGB 反预乘（`rgb*255/alpha`，numpy 两行），黑底加图的 screen 观感几乎无损还原为普通合成，任何层叠环境都稳；副作用的透明黑线条在深色页上不可见
