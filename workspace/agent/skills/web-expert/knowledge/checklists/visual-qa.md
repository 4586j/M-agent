# 视觉走查清单（G4 卡点配套）

对每个页面/每组改动执行。逐项勾选，结果与截图一并写入 `output/<项目名>/04-走查报告.md`。
发现新问题类型时按积累规则追加检查项（写明日期）。

## 1. 布局与间距

- [ ] 整体栅格/版心与设计稿一致（内容区宽度、左右留白）
- [ ] `document.scrollWidth == clientWidth`：装饰元素（光斑/画布/跑马灯）未撑出横向溢出（2026-08-30 增，源自 blog W4）
- [ ] 区块间距引用 spacing tokens（无临时 margin/padding 值）
- [ ] 元素对齐方式与设计稿一致（居中/两端/基线）
- [ ] 滚动行为正常（无意外横向滚动、无双重滚动条）
- [ ] sticky/fixed 元素遮挡关系正确

## 2. 文字与排版

- [ ] 字号/字重/行高与设计稿一致且引用 tokens
- [ ] 中英文混排无异常（字体回退正确、无豆腐块）
- [ ] 长文本换行正常（无溢出容器、有合理截断/省略策略）
- [ ] 数字/代码使用等宽字体（如设计有要求）

## 3. 颜色与图形

- [ ] 所有颜色来自 tokens（无硬编码 hex/rgb）
- [ ] 文字对比度：正文 ≥ 4.5:1，大字 ≥ 3:1
- [ ] 图标风格/尺寸/描边粗细统一
- [ ] 图片不变形（object-fit 正确）、已配置占位/懒加载

## 4. 交互状态（每个可交互元素逐个过）

- [ ] hover 状态有反馈且与设计稿一致
- [ ] 带导航的页面：页面顶端与各区块的导航高亮态都正确（含"回到顶部"状态，2026-08-30 增，源自 blog W1）
- [ ] active/按下状态正确
- [ ] focus 可见（键盘 Tab 遍历顺序符合视觉逻辑）
- [ ] disabled 状态不可点击且视觉正确
- [ ] 链接有明确可点击样式

## 5. 响应式（1280 / 768 / 375 三视口）

- [ ] 桌面端 ≥1280：无空白异常、栅格正确
- [ ] 平板 ~768：布局降级符合预期（不破版）
- [ ] 手机 ≤375：单列布局、触控目标 ≥44px、无横向滚动
- [ ] 断点之间过渡自然（无元素重叠/消失）

## 6. 边界情况

- [ ] 空态：列表/搜索无结果时有空态设计
- [ ] 加载态：有骨架屏或 loading 反馈
- [ ] 错误态：接口失败/表单校验错误的展示
- [ ] 极端数据：超长标题、0 条数据、极大数字、特殊字符
- [ ] 深色模式（如项目要求）：颜色均从语义 token 取值

## 7. 技术健康

- [ ] 控制台无报错/警告
- [ ] 网络请求无失败、无未处理的 404 资源
- [ ] 可访问性：图片有 alt、表单控件有关联 label、页面有唯一 h1
- [ ] 带 `hidden` 属性的元素确实隐藏（自定义 `display:flex/grid` 会压过 UA 的 `[hidden]` 样式，需全局 `[hidden]{display:none!important}` 兜底）（2026-08-30 增，源自 blog W5/W6）
- [ ] 页面标题（title）与 meta 已设置

## 8. 自动化走查适配（浏览器驱动）

- [ ] 走查前隐藏全视口游走型元素（如桌宠）与跟随鼠标的覆盖层（如透镜）——它们会恰好停在目标上拦截指针点击；走查后恢复默认态（2026-09-01 增，源自 blog 附录 F）
- [ ] 无头/内嵌浏览器指针输入通道失效时，改用页面内事件派发（evaluate click / requestSubmit + 原生 setter 注入值），并在报告注明"真实手势相关项"（如音频自动播放授权）转人工点验
- [ ] Windows 环回端口拒绝连接可能耗时 ~2s：离线类断言采样等待 ≥3s，或实现层加离线快速失败与健康探测短超时
- [ ] Canvas/游戏画面断言用像素探针而非截图：`getImageData` 统计非透明像素 + 关键坐标采样颜色；部分嵌入环境 rAF 请求后**从不触发**（即使 visibilityState=visible），帧循环必须带看门狗（如 400ms 未触发落 setTimeout），否则画布永远黑屏（2026-09-05 增，源自 pet-client W3）
- [ ] 双开标签页模拟多用户时，会话必须存 sessionStorage（localStorage 跨标签页共享会互相顶号）；共享数据每次操作前重读，防止"整库加载一次+写回"把另一标签页的写入覆盖掉（2026-09-05 增，源自 pet-client W6）
