## 示例

> **ADR-001：默认采用 React + Vite + Tailwind 作为新项目技术栈**
> 背景：多数任务为中小型页面，Next.js 的 SSR 能力常被闲置。
> 决策：默认 React + Vite + Tailwind，需要 SEO/服务端能力时升级 Next.js。
> 备选：Vue 3 + Nuxt（团队无偏好时不引入第二栈）、纯 HTML（交互复杂时不可维护）。
> 后果：正面积累统一、AI 生成质量稳定；代价是 SEO 型官网需额外迁移。影响 S3 阶段与 toolchain.json 的 dev 类默认值。
