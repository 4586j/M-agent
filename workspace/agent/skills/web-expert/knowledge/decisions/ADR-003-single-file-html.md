# ADR-003：博客首页采用零依赖单文件 HTML（而非默认 React + Vite）

- 日期：2026-08-30
- 状态：accepted

## 背景

toolchain.json 的 dev 类默认栈是"React + Vite + Tailwind"（可选项）。本项目是个人博客**首页演示**：要求动画多、特效炫酷、信息多，但无正文页、无后端、无真实数据；交付环境以"直接打开预览"为主。

## 决策

单文件 `output/blog/index.html`（内联 CSS/JS），动效全部 vanilla 实现（IntersectionObserver + rAF + CSS 动画），样式变量从 tokens.json 生成。理由：零构建、零依赖、双击即可打开、动效代码本身就是"手写特效"的展示品。

## 备选方案（为什么没选）

- **React + Vite + Tailwind（默认栈）**：需要 npm install 与构建环节，交付物变成"项目"而非"页面"；对本项目规模收益为负。若后续扩为多页博客/接入真实数据，按此 ADR 的"升级路径"迁移。放弃（暂时）。
- **GSAP + Lenis（2026 流行组合，调研要点 3）**：能力强但引入 CDN 依赖，离线打开会失效；vanilla 等价实现覆盖本项目全部 12 项动效。放弃。

## 后果

- 正面：交付/预览成本最低；P1 tokens 纪律通过"生成式 CSS 变量"维持。
- 代价：无组件系统，复用靠登记"效果组件"锚点；页面超 2000 行后维护成本上升。
- 升级路径：需要文章详情页/真实数据/多页共享组件时 → 迁移 React + Vite，效果组件按 registry 登记项逐个重写。
