# 待机动画方案与接入边界

> 文档类型：当前待机能力、使用边界及设计历史；最后核对：2026-10-18。用户已选定呼吸花园，个人 Agent 面板与编排前端已接入（工作区）；原五套候选保留独立预览，团队工作台未接入。

## 正式界面使用

- 个人面板 `http://127.0.0.1:8000/panel` 与编排前端（例如构建后由 Brain 托管的 `http://127.0.0.1:7000/`）顶部均有「待机」菜单。默认闲置 5 分钟，可选 1/5/10/15 分钟或关闭自动进入，也可点击「立即待机」。已有个人服务需重新启动以加载新增资源路由，编排前端需重新构建；Vite 开发模式直接加载共享模块。
- 默认流线花冠，保留星尘花园切换、亮度、时钟与减少动态设置。正式设置与设计室偏好独立，localStorage 使用 `m-agent.standby.personal.settings` / `m-agent.standby.orchestration.settings`，不包含对话、任务、费用、凭据或工作区数据；同源同界面的设置变化可同步。
- 指针、键盘、滚轮、触摸和输入均算操作；SSE、轮询或任务产生输出不算人的操作。后台标签恢复可见或窗口获得焦点时立即核对最后操作时间，不因后台计时器被浏览器降频而重新给予完整等待时间。
- 进入时使用不透明原生 modal 顶层遮挡，底层现有及新增 body 子节点设为 inert/aria-hidden，并限制焦点。鼠标移动/轻点仍可玩花园，R 唤起涟漪；不会因此退出待机。长按返回约 650ms，或聚焦返回后按 Enter/空格、辅助技术明确激活，才恢复。短按、Escape、移出按钮的长按不会恢复；应用快捷键不会穿透到派发、搜索或后台表单。
- sessionStorage 按标签和界面保存最后操作时间与待机状态。刷新已遮挡/已超时页面时，内联启动检查先隐藏工作内容，组件就绪后显示花园；显式恢复才清除待机。恢复不跨标签广播。设置存储不可用时仍可在内存中使用，但不能承诺跨刷新保存。
- 不卸载工作应用，不取消后台任务、网络请求、会话、连接或轮询；返回保留现有草稿和可用焦点。只通过 `m-agent:standby` 事件暂停/恢复宿主装饰粒子动画。花园目标约 60 FPS、DPR 上限 2；待机未开启或页面不可见时不绘制，减少动态下静态呈现。

共用实现为 [standby.js](../agent_core/panel/standby.js) 和 [bloom.js](../agent_core/panel/bloom.js)。个人页面通过 `/agent/panel-assets/standby.js` 加载，服务只允许 `standby.js`、`bloom.js`；React 通过 [StandbyControl](../web/src/components/StandbyControl.tsx) 挂载并在卸载时清理监听器/计时器，清理不当作用户恢复。两者的外观/样式使用 Shadow DOM，遮挡使用浏览器原生顶层，避免受应用布局、overflow 或门户层级影响。

这里只提供浏览器页面的旁观遮挡，不提供 PIN、登录重验或操作系统锁屏，不改变既有鉴权/会话有效期。恢复后原有业务授权仍由后端判断，不使用待机状态绕过错误或续期。首版覆盖现代 Chromium；其他浏览器、系统级旁观保护及团队 UI 不在本轮验收范围。

## 方案与体验入口

预览源码在 [standby-lab](../web/public/standby-lab/index.html)，只使用本地 CSS、Canvas 与系统字体，不连接模型、业务 API 或外部素材。不展示真实任务、成员、费用、对话或文件内容。

| 方案 | 动态设计 | 风格与建议 |
| --- | --- | --- |
| 引力编队 | 不同轨道的微光节点绕同一核心运行，带缓慢呼吸与轨迹 | 原候选，保留在设计室 |
| 极光织幕 | 青蓝色光丝叠加成连续流动的帘幕 | 更强调沉浸和视觉记忆点 |
| 水墨远山 | 冷灰山峦、雾层、月光与远鸟缓慢位移 | 东方留白，适合长时间观看 |
| 呼吸花园 | 流线花冠以细线和沿线微光舒展；星尘花园以细小粒子聚散成花形 | 用户已选定并接入个人/编排界面 |
| 折光矩阵 | 等距几何单元形成起伏地景，冷暖光泽缓慢交替 | 建筑与秩序感，适合团队控制台 |

从仓库根运行：

```powershell
python -m http.server 7078 --bind 127.0.0.1 --directory web/public
```

打开 `http://127.0.0.1:7078/standby-lab/`。Vite 或生产静态资源服务也可通过 `/standby-lab/` 访问。已启动的独立预览不重启现有 Agent 服务。

页面提供五个实时缩略图、大画面切换、全屏体验、五秒离开演示、闲置时长、亮度、强度、时钟、暂停与减少动态开关。选择偏好只保存到本机 localStorage，不会自动替用户决定正式方案。

呼吸花园根据视觉反馈去掉原来的密集实心叶片，提供「流线花冠」与「星尘花园」两个子方案，选择后在说明下方切换，支持全屏与本机偏好保存。直达预览可使用 `?scene=bloom&bloom=lines` 或 `?scene=bloom&bloom=particles`；仅指定 `?scene=bloom` 时沿用已保存的表现方式。减少动态或暂停时切换仍会重绘静态画面。

两种花园表现均支持交互：鼠标靠近时局部细线/粒子柔和偏转，移开后逐渐恢复；点击或触屏轻点时泛起涟漪与少量微光，约 1.8 秒消退，同时最多保留四圈。页面「唤起涟漪」按钮支持键盘激活，全屏时可按 R 在花冠中心唤起。移动、轻点和 R 不会解除遮挡；点击返回控件不生成花园涟漪。触屏不拦截默认滚动，取消触摸后结束指针作用。暂停、减少动态、页面隐藏、方案切换及进入/退出遮挡时清除交互状态；暂停或减少动态时不接受新交互。

## 遮挡与恢复

实际闲置检测监听指针、键盘、滚轮和触摸，活动后重新计时；预览默认五分钟，可选十五秒、一分钟或关闭。五秒演示独立计时，便于比较交互。

进入待机时立刻显示不透明全视口遮挡，并将底层设计室设为 inert 和 aria-hidden，约束键盘焦点。移动鼠标、短按返回或按 Escape 不会露出底层；Escape 退出浏览器原生全屏后仍保留遮挡。按住返回约 650ms，或聚焦按钮后按 Enter/空格、使用辅助技术明确激活，才恢复并归还焦点。按住期间移出按钮取消该次恢复。

这属于旁观遮挡，不是身份验证锁屏。正式实现同样不增加会话重新验证；不能把前端遮罩当作登录、退出或服务端授权。设计室不连接任务执行，因此不展示虚构的运行状态。

## 性能、可访问性与后续接入

单一绘制循环中，主画面目标约 60 FPS，缩略图独立限制为约 12 FPS，设备像素比最高为 2；累积帧间余量，避免按固定阈值重置计时造成刷新间隔不均。跳过不可见画布，遮挡时只绘制全屏画布，页面隐藏时停止绘制。花园缓存粒子属性和渐变，花瓣/涟漪共享参数每帧计算一次，无有效指针时跳过指针形变计算。尊重系统减少动态偏好并显示静态帧；无声音，不依赖图片、视频、外链字体或 WebGL。移动端方案列表横向滚动，页面本身不横向溢出。

2026-10-18 本地 Chromium 性能采样：1440×1050 视口，每场景预热 350ms、采样约 2.6 秒，连续指针移动与约每 240ms 点击。DPR 1 下，优化前线条交互约 28.2 FPS、绘制间隔 P95 约 37.8ms；优化后约 60 FPS、P95 约 18ms，五个缩略图总重绘从 365 次降至 155 次。优化后粒子交互、全屏线条也约 60 FPS；DPR 2 的线条/粒子交互约 60 FPS、间隔 P95 为 18.4/18.2ms。数值由绘制入口和动画回调临时探针采样，代表本机浏览器绘制调度，不能等同于所有设备的 GPU 合成、显示器实际呈现或长期运行保证；生产代码不保留探针。
