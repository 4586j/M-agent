# 编排界面与单 Agent 面板回归修复

日期：2026-10-14。Git 基线：`main`，`b15dff6`。

修复基于工作区已有的界面改动进行。本轮未提交；Git 暂存区为空，没有执行回退或远程推送。

## 修复范围

| 审查问题 | 修复 |
| --- | --- |
| AI 标题回传时覆盖新轮次和人工标题 | 保存轮次时在锁内合并最新会话；标题只更新相关字段。模型回传时比较标题版本与原值，拒绝过时结果；人工命名后自动提炼不会覆盖它 |
| 任务详情抽屉被转场容器限制 | 使用 React Portal 挂载到 `document.body`，抽屉与遮罩按整个视口定位；保留视图转场效果 |
| 会话重命名发送 `[object Object]` 导致 422 | 显式序列化 JSON 并设置请求头，操作捕获目标会话 ID |
| 标题中的双引号截断编辑框内容 | 创建输入框后通过 `.value` 设置标题，不再将标题拼入 HTML 属性 |
| 侧栏滑动高亮找不到当前页面 | 通过 `aria-current="page"` 定位，使用相对导航容器的实际坐标，避免分组定位偏差 |
| 标题提炼费用漏记 | `/agent/status` 新增 `title_usage`，记录调用数、失败数、费用、轮次及 token；`/usage` 和 `/cost` 展示该统计，未知费用单独标记 |
| 筛选按钮换行后高亮跨行 | 记录所选按钮的上、左、宽、高，并在容器、按钮尺寸和计数改变时重新测量 |

会话历史合并与标题版本检查使用进程内锁，与现有单进程服务部署方式一致。此修复不代表任务 JSON 存储已支持多进程共享写入。用量统计仍按当前服务进程累计；SDK 回传费用不等于供应商套餐账单。
