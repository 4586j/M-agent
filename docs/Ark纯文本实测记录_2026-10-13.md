## 测试入口调整与补充验证

[真实 SDK 冒烟测试](../agent_core/tests/test_sdk_smoke.py) 原先只接受 `ANTHROPIC_API_KEY`，现支持 `ANTHROPIC_AUTH_TOKEN + ANTHROPIC_BASE_URL`，显式读取 `ANTHROPIC_MODEL`，禁用工具与 MCP，并新增真实费用经过本地预算派发链路的测试。

测试仍需显式设置 `RUN_AGENT_SDK_SMOKE=1`；未启用时两项均跳过，不产生模型调用。已在正常本机测试环境验证：预算确定性回归 **26 passed**，真实 SDK 用例默认 **2 skipped**，1 条现有依赖弃用告警。首次在沙箱中补跑时因无法创建 pytest 临时目录而中止，切换正常本机测试环境后通过。Ruff 与差异格式检查通过。

已在进程环境设置认证和模型配置后，可运行：

```powershell
$env:RUN_AGENT_SDK_SMOKE = '1'
python -m pytest agent_core/tests/test_sdk_smoke.py -q -s --tb=short
```

本次覆盖真实模型与本地派发结算；安全检查在该隔离测试中使用固定通过结果，没有验证安全模型、远程 Worker、真实取消中断、工具执行或图片能力。第二批已有的确定性回归覆盖相关取消与恢复逻辑。本轮新增测试和记录尚未提交，未部署服务。
