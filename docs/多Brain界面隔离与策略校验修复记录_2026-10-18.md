# 多 Brain 界面隔离与策略校验修复记录

日期：2026-10-18。Git 基线：`main` / `b15dff6`。本轮基于已有未提交改动继续修复，未执行提交、回退或推送。

## 修复范围

| 问题 | 修复后的行为 |
| --- | --- |
| 核心记忆草稿切换后可能保存到另一 Brain | 页面统一由 `BrainScope` 管理生命周期。切换 Brain、修改地址或密钥时重建当前页面，清空记忆编辑、Provider/调度创建、节点路径输入和任务详情等状态 |
| 只修改连接地址，轮询与抽屉未立即失效 | 新增统一连接配置标识，包含连接 ID、规范化地址及进程内配置版本；地址或密钥变化立即使轮询、订阅及页面失效。仅修改名称保留草稿和数据 |
| 任务 A 的迟到详情覆盖任务 B | 任务或连接变化后取消旧详情请求、关闭事件流与定时器；即使请求不响应取消，生命周期及配置检查仍会丢弃结果。同一任务较早响应也不覆盖已展示的较新响应 |
| 终态 SSE 快照关闭连接后未刷新结果 | 更新快照状态并请求最终输出；降级轮询发现终态后停止，列表刷新通知去重；终态事件之前发出的请求不能覆盖最终结果 |
| 合法 JSON 的策略结构或字段类型错误导致异常 | 应用任何覆盖前先完整校验。根节点及边界策略必须为对象；两个开关必须为布尔值；确认粒度为既有枚举；预授权目录为非空绝对路径字符串的数组。任一已知字段无效时告警并整体回退默认值 |
| 删除知识文档连续确认两次 | 保留删除函数内的一次确认；拒绝时不发送删除请求 |

连接配置标识使用进程内版本号表示密钥变更，不包含密钥本身，不把密钥写入组件 key 或 DOM。会话选择仍按之前的连接 ID 与地址保存；本轮没有迁移或删除后端历史。

页面重建意味着切换 Brain、修改地址或密钥时放弃当前未提交草稿。已经提交到原 Brain 的请求仍属于原 Brain；前端切换不会撤销后端已经接受的写入或任务。

## 响应顺序与慢网络

通用轮询同时检查连接配置、组件生命周期和响应顺序。在较新的响应已经落地后丢弃旧响应；如果新请求尚未完成，允许同一连接已有的有效响应显示，避免请求耗时超过轮询间隔时始终没有数据。

任务详情同样保留响应顺序检查；终态事件额外建立边界，拒绝终态事件之前的详情响应。

## 策略兼容性

- 合法的 `false` 不会被字符串或数字混淆；缺省字段继续采用内置默认。
- 无效策略整体回退，避免 `enforce=false` 与另一个错误字段组合时留下部分放宽的状态。
- 保留对未知字段的忽略行为。
- 相对目录不再作为有效的预授权目录，配置需使用服务所在系统的绝对路径。
- 当前本地 `.agent_policy.json` 保持有效默认配置，测试仍在临时项目根运行。
- 策略仍按服务进程缓存，代码和策略更新需要重启后端后生效。
